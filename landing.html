The crew

Built to work alone

Fully autonomous

Give it the task and it carries it through from first look to finished result. It stops the moment the job is done instead of padding the run with extra checks.

Routes by artifact

PE, ELF, WASM, Office files, .NET assemblies and JARs each get the right tool. Disassembly, emulation, YARA, entropy and carving are all within reach.

Proves its findings

A claim only counts once Oxygen has run it for real and written a reproduction script you can run yourself.

Lives on your machine

A small local agent bridges the browser to your box. Writes stay inside the project folders you connect, and every path is absolute.

Remembers the project

Persistent memory keeps notes per project, so the next session starts from what the last one learned.

Desktop or browser

One engine, two front-ends: an Electron app and a web UI with chat, a terminal, an IDE file tree and editor, and a model dropdown.
